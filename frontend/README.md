# Frontend — Сервисный центр

Frontend часть командного проекта «Сервисный центр».

Разработка интерфейса приложения: страницы, навигация, отображение заявок, работа с ролями пользователей и основные действия с заявками.

На данный момент frontend работает на тестовых данных. После завершения интерфейса он будет подключён к backend на FastAPI через API.

---

## Запуск проекта

Для запуска frontend необходимо открыть папку frontend в терминале и выполнить:

npm install

После установки:

npm run dev

После этого Vite запускает локальный сервер, обычно по адресу:

http://localhost:5173/

## Что уже реализовано

На текущем этапе реализованы основные части интерфейса сервисного центра.

### 1. Главный экран

При запуске приложения пользователь видит:

- название системы;
- краткое описание;
- кнопку «Войти в систему».

### 2. Авторизация

Сделан тестовый экран входа в систему.

Пользователь вводит:

- логин;
- пароль.

Сейчас авторизация работает на тестовых данных из `mockData.ts`.

После успешного входа пользователь попадает в панель управления.

### 3. Роли пользователей

Для тестирования frontend добавлены несколько ролей:

- клиент;
- оператор;
- инженер;
- мастер;
- администратор.

Для каждой роли в дальнейшем будут доступны свои функции.

### 4. Панель управления

После входа открывается Dashboard.

В нём есть:

- боковое меню;
- информация о пользователе;
- статистика по заявкам;
- список последних заявок;
- переход к полному списку заявок.

### 5. Работа с заявками

Реализован список заявок.

Для каждой заявки отображаются:

- номер;
- клиент;
- устройство;
- текущий статус.

Заявку можно открыть и посмотреть подробную информацию.

### 6. Страница заявки

На странице заявки отображаются:

- номер заявки;
- клиент;
- устройство;
- текущий статус;
- история обработки заявки.

Также в зависимости от роли пользователя отображаются доступные действия.
